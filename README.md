# BIOSTAT721-Project-2:  Air Pollutant Analysis in RDU Airport (Jan. 2018 ~ Apr. 2020)
## Purpose:
The purpose of this project is to process and analyze daily air pollutant quality (CO, O<sub>3</sub>, PM<sub>2.5</sub>) measured at the Raleigh-Durham (RDU) Airport EPA monitor from January 2018 ~ April 2020. In doing so, these analyses provide a broader investigation into air pollution and sickle cell disease in Durham County, NC. This project consists of summaries of annual pollutant ranges (minimum and maximum daily concentrations) and visualizes seasonal trends using two plots: (1) pooled monthly means and 95% confidence intervals for CO and O<sub>3</sub>; (2) PM<sub>2.5</sub> concentrations across years. 

## Data Source:
EPA monitor at RDU Airport from January 2018 ~ April 2020.
