# BIOSTAT721-Project-2:  Air Pollutant Analysis in RDU Airport (Jan. 2018 ~ Apr. 2020)
## Purpose:
This project processes and analyzes daily air pollutant quality (CO, O<sub>3</sub>, PM<sub>2.5</sub>) measured at the Raleigh-Durham (RDU) Airport EPA monitor from January 2018 to April 2020. These analyses provide a broader investigation of air pollution and sickle cell disease in Durham County, NC. This project consists of summaries of annual pollutant ranges (minimum and maximum daily concentrations) and visualizes seasonal trends using two plots: (1) pooled monthly means and 95% confidence intervals for CO and O<sub>3</sub>; (2) PM<sub>2.5</sub> concentrations across years. 

## Data Source:
The following files are integrated into this project for data processing using R-Programming/RStudio (i.e.: data cleaning, data management, table/plot analysis):
- AQ_2018.csv: Air quality from Jan. 2018 ~ Dec. 2018
- AQ_2019.csv: Air quality from Jan. 2019 ~ Dec. 2019
- AQ_2020.csv: Air quality from Jan. 2020 ~ Apr. 2020
